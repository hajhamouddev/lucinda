# Verify online

Follow these steps in order.

1. **Get the date.** Run `date` and note today's date. Use it in queries when recency matters.
2. **Write 2-3 different queries.** Different wording and angle each time, not the same query repeated.
3. **Prefer primary sources.** Official docs, release notes, the vendor's site, the project's
   repository and changelog. Use blogs, forums and reviews only to cross-check.
4. **Open the pages.** Do not rely on search snippets. Fetch the page and read the part that answers the question.
5. **Cross-check.** Confirm every important claim in at least 2 independent sources.
   Check the date of each source. A source older than the question's timeframe is not enough.
6. **Handle newest-thing questions carefully.** For "what is the newest X", search for the
   release list of X, find the latest entry by date, then confirm with a second source. Never name
   a "latest" item from memory.
7. **Answer in this shape:**
   - Answer (1-3 lines)
   - Sources: name + date for each
   - Confidence: high / medium / low, and why
   - Anything that conflicts or could not be verified
8. If you cannot verify it, say exactly: "I couldn't verify this." and list what you tried.
   Do not fill the gap with a guess.
